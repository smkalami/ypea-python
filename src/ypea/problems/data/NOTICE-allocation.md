# Bundled instance data for the allocation problems

## gap_orlib_gap1.txt

Source: OR-Library, J. E. Beasley, generalized assignment problem, file `gap1`
(https://people.brunel.ac.uk/~mastjjb/jeb/orlib/gapinfo.html). The file is unchanged.

The problems were used in I. H. Osman, "Heuristics for the generalised assignment problem:
simulated annealing and tabu search approaches", OR Spektrum 17 (1995) 211 to 225, and in
D. Cattrysse, M. Salomon and L. N. Van Wassenhove, "A set partitioning heuristic for the
generalized assignment problem", European Journal of Operational Research 72 (1994) 167 to 174.

## hub_orlib_phub4.txt

Source: OR-Library, J. E. Beasley, p-hub location, file `phub4`, the CAB data set contributed
by M. E. O'Kelly (https://people.brunel.ac.uk/~mastjjb/jeb/orlib/phubinfo.html). The file is
unchanged.

Reference: M. E. O'Kelly, "A quadratic integer program for the location of interacting hub
facilities", European Journal of Operational Research 32 (1987) 393 to 404.
